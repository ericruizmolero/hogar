# Hogar

Aplicacion web para buscar, guardar y comparar propiedades inmobiliarias. Importa anuncios de portales como Idealista, Fotocasa o Pisos.com y gestionalos desde un unico sitio.

## Stack

- **Frontend:** React + TypeScript + Vite + Tailwind CSS
- **Backend:** Firebase (Auth, Firestore, Storage)
- **Deploy:** Vercel
- **Proxy de imagenes:** Vercel Edge Functions

## Desarrollo local

```bash
npm install
npm run dev
```

## Deploy

Conectado a Vercel via GitHub. Cada push a `main` despliega automaticamente.
